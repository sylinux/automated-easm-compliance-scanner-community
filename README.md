# Automated EASM Compliance Scanner

A production-grade, passive **External Attack Surface Management (EASM)** compliance engine designed to continuously audit network interactions with legacy institutional gateways without triggering active SOC firewall alarms. Due to the length and detail of the configuration files, prerequisites, and JSON payloads, you can find the complete implementation, setup commands, cron integrations, and enterprise licensing details directly in the referenced source repository.

## Key Features & Overview
- **Passive Recon Telemetry:** Executes compliant passive metadata harvesting to map internal domain leakage, edge security fingerprinting, and inter-department handoff routing without hostile active port probing.
- **Quick Start & Usage:** Includes local validation and stealth compliance modes via Tor proxy routing.
- **Telemetry & Monitoring:** Generates structured JSON compliance reports (`compliance_report.json`) suitable for SIEM ingestion and automated daily cron tracking.
